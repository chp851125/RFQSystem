# 詢比議價系統 Demo（RFQ System）

用來了解企業「詢價 → 比價 → 議價 → 決標 → 採購」流程與常見功能的示範系統。

- ASP.NET Core MVC（.NET 10）＋ Bootstrap 5
- **不需要資料庫**：資料全部是記憶體內的假資料，網站重新啟動就回到初始狀態
- 介面為繁體中文，每個頁面都有黃色說明框解釋該功能在企業中的用途

## 執行方式

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)。

**Visual Studio：** 開啟 `RFQSystem.slnx`，按 F5。

**命令列：** 在本資料夾執行

```powershell
dotnet run --project RFQSystem
```

開啟 http://localhost:5164 。

- 採購內部系統：首頁（登入者固定為「王小華（採購專員）」）
- 供應商入口網站：右上角「供應商入口網站 ↗」
- 想把資料恢復原狀：儀表板右上角「重置示範資料」，不必重新啟動

## 標準流程

```
建立詢價單 → 邀請供應商 → 供應商報價（密封） → 開標 → 比價 → 議價（可多輪）
          → 決標 → 依金額簽核 → 轉採購單 → （選用）建立合約價 → 依合約下單
```

建議第一次使用時：
1. 打開選單「功能說明」，了解每個功能與名詞。
2. 開啟狀態為「草稿」的 **RFQ-2026-0006**，照頁面上方的按鈕一步步走完整個流程。

## 功能一覽

| 功能 | 說明 |
|---|---|
| 儀表板 | 進行中詢價、待簽核、決標金額、議價節省金額、即將到期合約 |
| 詢價單 | 料件、數量、需求日、目標價（內部預算，不給供應商看）；可選密封或公開報價 |
| 供應商主檔 / AVL | 品質分數、準交率、等級；只有合格供應商（AVL）能被邀請；少於 3 家會提醒「三家比價」 |
| 供應商入口網站 | 供應商自行報價（截止前可修改、可婉拒）、回覆議價、查看決標結果、確認接單、查看合約 |
| 密封報價 / 開標 | 開標前連採購也看不到價格；過截止日或全部廠商回覆後才能開標，需指定監標人，並產生開標紀錄 |
| 階梯報價 | 依數量給不同單價（最多 4 階）；比價頁可試算不同數量下誰最便宜 |
| 比價分析 | 並排比較、標示最低／最高價、對照目標價與上次採購價；價格／交期／品質加權評分 |
| 議價 | 多輪還價，保留每一輪價格；有階梯價時整組等比例調整 |
| 決標 | 可分批決標；未選最低價必須填理由 |
| 簽核 | 依金額分層：一律採購主管；≥ 50 萬加財務協理；≥ 200 萬加總經理；可核准或退回 |
| 採購單 | 決標後依得標供應商自動拆單；可列印 |
| 合約價 | 由決標建立、依合約下單、承諾量追蹤、到期提醒、一鍵續約詢價、新約取代舊約、終止合約 |
| 料件與歷史價 | 歷次成交價與價格趨勢圖 |
| 稽核紀錄 | 每張詢價單與合約的所有動作、人員、時間 |

## 專案結構

```
RFQSystem/
├─ Services/MockDb.cs        記憶體假資料庫：所有業務規則與初始範例資料都在這裡
├─ Models/Domain.cs          資料模型（詢價單、報價、階梯價、合約、採購單…）
├─ Models/ViewModels.cs      比價分析與加權評分計算、表單模型
├─ Controllers/
│  ├─ HomeController.cs      儀表板、功能說明、重置資料
│  ├─ RfqController.cs       詢價單全流程
│  ├─ ContractsController.cs 合約價
│  ├─ PortalController.cs    供應商入口網站
│  └─ MasterDataController.cs 供應商、料件、採購單
├─ Views/                    各頁面（Portal/ 有自己的版面）
└─ wwwroot/js/site.js        階梯報價的前端計算
```

想了解某個規則怎麼運作，從 `Services/MockDb.cs` 開始看最快。
